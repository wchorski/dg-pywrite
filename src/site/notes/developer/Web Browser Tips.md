## Copy a link without going to the page
So many times I would click a link just so i could copy it's address and path in the address bar to send in a message or copy into documentation. 

If you `right click` the link text you can `Copy Link`. This is true for all browsers.

What if you're on a site that hijacks the right click, such as Google Drive or Spotify? Then just hold `Shift` and `right click`. This bypasses and uses the native context window.
